About

smol-gitstat-web visualises the history of a git repository from a JSON file produced by smol-gitstat. It shows activity over time as charts and a summary table, and a browsable commit list, with grouping by author, project or file type and configurable filters.

Privacy: uploaded data never leaves the browser. It is parsed and stored locally on this device, and can be removed at any time with the “Clear data” button on the upload page.

It is a rewrite of gitstat-web by Niels Krijger, the source of gitstat.com. Thanks for the original idea and implementation.
