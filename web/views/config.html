How patterns match

Each line is a regular expression tested against the full file path (like src/charts/line.js), unanchored and case-sensitive. Folder names are part of the path, so patterns match them too. Escape regex characters like . with a backslash when you mean them literally.

  • \.ts$ — files with the .ts extension
  • legacy — any path containing "legacy"
  • ^src/ — everything under the top-level src folder
  • node_modules/ — a node_modules folder at any depth
